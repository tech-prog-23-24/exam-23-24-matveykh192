### Задание 2

**На основе паттерна singleton (любой из реализаций) написать класс:**

#### Менеджер аудио в игре

**Условие:**  
Создайте класс `AudioManager`, который управляет звуками в игре.

**Требования к классу:**
- Методы:
    - `playSound(const string& name)` – воспроизведение.
    - `stopSound(const string& name)` – остановка.
    - `setVolume(float volume)` – громкость.
    - `loadSound(const string& path)` – загрузка.
    - `pauseAll()` – пауза.
    - `resumeAll()` – возобновление.
    - `isPlaying(const string& name)` – проверка.

Для демонстрации работы класса написать консольное приложение без Qt, которое использует все методы класса.

**В качестве ответа допускаются файлы с расширениями:**  
`.c`, `.cpp`, `.h`, `.hpp`, `.txt`, `.pro`, `.db` и скрины или видео работы.
